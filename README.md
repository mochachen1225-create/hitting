# 小人退散

打小人的手機網頁小遊戲。輸入你想退散的對象，選一種方式把紙小人打到爛掉，最後領一張專屬符咒，傳給朋友一起神清氣爽。

**直接玩**：<https://mochachen1225-create.github.io/hitting/>（手機、電腦都可以，手指和滑鼠都能操作）

## 玩法

1. 開場選中文或 English（瀏覽器不是中文的玩家會預設英文）。
2. 輸入對象的名字或稱呼。不填就叫「臭小人」。名字會寫在紙小人身上，只存在你自己的瀏覽器。
3. 從 10 種退散法自己挑一種，或按「隨機抽一個」，或玩最上面的「今日挑戰」，或選「親手畫符」。
4. 每局最長 60 秒（拖鞋是 30 秒計時賽）。小人會逃、會閃、會嗆你，要追著打。
5. 打擊時偶爾會出現「暴擊！×2」，一次算兩下。
6. 打完畫面轉成日出，「神清氣爽～」。
7. 接著擲筊問神明「小人退散了嗎？」：一平一凸是聖筊，連續三個聖筊運勢升成上上籤；笑筊、陰筊就再擲（最多 5 次，也可以略過）。
8. 偶爾會遇到貓貓神下凡祈福：抓住會逃跑的小魚乾，拖去獻給牠，運勢升級成上上籤。
9. 結算依速度給評級 S／A／B／C，破紀錄會顯示「新紀錄！」。
10. 領取符咒圖，用「分享符咒圖」傳到 LINE、Threads 或任何 App。分享文字會附上你的成績和遊戲網址，朋友點了就能挑戰。

手機瀏覽器選「加入主畫面」，就會有遊戲圖示，打開是全螢幕，像 App 一樣。

## 10 種退散法＋親手畫符

| 玩法 | 怎麼操作 | 過關條件 |
|---|---|---|
| 射飛鏢 | 從下往上滑，射出飛鏢 | 射中 10 次 |
| 拖鞋打 | 追著亂跑的小人點下去，口訣字幕跟著打的速度跑 | 30 秒內打 100 下拿金拖鞋獎（70 下銀、40 下銅） |
| 燒掉 | 按住拖著蠟燭追，火一離開就熄 | 燒成灰 |
| 釘草人 | 點小人敲釘子；一指按住它、另一指敲會更準 | 釘滿 10 根 |
| 撕碎 | 手指劃過就撕開，也能兩指往外拉 | 撕成 60 片 |
| 揉爛丟掉 | 在小人身上來回搓成紙團，再往上甩進飄來飄去的垃圾桶 | 投進垃圾桶 |
| 泡水 | 抓住小人拖進水裡壓著，它會躲手指、會溜走 | 泡到爛掉 |
| 搖到暈 | 搖手機，或抓住罐子用力甩 | 撞罐子 20 下 |
| 節分撒豆 | 點畫面撒豆子打戴鬼面具的小人，金色「福」字點到加 3 | 打中 40 顆 |
| 祭改燒替身 | 把黑色煞氣拖進紙替身 → 小三牲擺上供盤 → 替身丟進金爐 | 三步完成 |
| 親手畫符 | 在黃紙上畫一道符，看準時機把符貼到小人額頭 | 貼上就封印（不計評級） |

## 今日挑戰

每天固定一種玩法，加上一個當日特殊規則，同一天所有玩家都一樣，可以跟朋友比成績：

| 特殊規則 | 效果 |
|---|---|
| 暴擊率 ×3 | 暴擊更常出現 |
| 限時 30 秒 | 時間上限從 60 秒縮成 30 秒 |
| 小人縮小 | 小人變小，更難打中 |
| 小人變大 | 小人變大 |
| 原汁原味 | 沒有特殊規則 |

連續每天完成會累積「連續 N 天」，選單橫幅會顯示今日最佳成績。今日挑戰的成績另外記錄，不算進下面的退散圖鑑。

## 民俗圖鑑

選單的「📜 民俗圖鑑」收錄 13 張卡，玩過對應的玩法或步驟就會解鎖。每張卡都標明是「傳說改編」「靈感改編」還是「遊戲原創」，中英文都有。

> **純屬娛樂**：遊戲裡的習俗介紹都是傳說與遊戲改編，不是真實歷史或宗教建議，也沒有任何效力。

## 成就

選單的「🏆 成就」有 23 個成就（中英對照），例如連擊 30、金拖鞋、三聖筊、貓奴、連續 7 天、丑時退散。成就越多，分享符咒越華麗：5 個金色字、10 個朱砂光框、15 個「退散大師」印。

## 符咒圖

每局結束都會產生一張 1080×1500 的符咒圖：

- 草書「敕令」，中間的符文是「小人退散」的注音 ㄒㄧㄠˇ ㄖㄣˊ ㄊㄨㄟˋ ㄙㄢˋ
- 兩側長紅條、皺紙紋、隨機吉祥話印章
- 寫上你退散的對象、退散方式和今日運勢

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 完整遊戲，單一檔案，GitHub Pages 直接開這個 |
| `src/game.html` | 遊戲本體原始檔，修改都改這裡 |
| `tools/build.sh` | 把 `src/game.html` 包成 `index.html`，加上分享預覽標籤 |
| `tools/smoke.js` | 自動把 8 種玩法各玩到結束，檢查有沒有錯誤 |
| `og.png` | 貼連結到社群時的預覽圖（1200×630） |
| `icon-*.png`、`manifest.webmanifest` | 加入主畫面用的圖示和設定 |
| `tools/make-images.js` | 用遊戲的繪圖程式重新產生預覽圖和圖示 |
| `assets/` | AI 生成的背景、符咒、貓貓神（WebP） |
| `tools/prep-art.py` | 把原始 AI 圖轉成 `assets/`（縮圖、壓縮、去背），檔案對應寫在腳本裡 |
| `VERSION` | 版本號（要和 `src/game.html` 的 `VERSION` 常數一致） |
| `tools/package.sh` | 打包 itch.io（含 AI 圖）和 Newgrounds（無 AI 圖）的上傳壓縮檔到 `dist/`，Mac、Linux 都能跑 |
| `tools/make-promo.js` | 從真實遊戲拍中英文截圖和 itch 封面到 `promo/` |
| `promo/` | 上架用截圖（`en/`、`zh/`）、itch 封面、試玩廣告 `trailer-zh.mp4`／`trailer-en.mp4`（直式 28 秒）、廣告配樂 `audio/`（AI 生成） |
| `tools/trailer/` | 試玩廣告：`stage.js` 用虛擬時鐘連拍遊戲畫面、`cards.js` 做字卡和片尾卡、`build.py` 用 ffmpeg 剪輯配樂 |
| `docs/itch-page.md` | itch.io 上架設定、中英文案、AI 標示、標籤 |
| `tools/serve.js` | 測試用的本機伺服器（用 `file://` 開的頁面不能匯出含圖片的符咒） |
| `NOTES.md` | 開發進度、設計決定、還沒做的想法 |
| `CHANGES.md` | 玩家看得懂的版本更新紀錄（中英） |

修改流程：改 `src/game.html` → `sh tools/build.sh` → `node tools/smoke.js` → 更新 `NOTES.md`。

## 素材來源

**圖像**
- **AI 生成**：12 張場景背景、符咒紙、兩張裝飾版符咒（分享圖用）、貓貓神（5 種花色）、小魚乾、紙小人的紙紋理與輪廓、藍白拖、16 種道具（筊杯兩面、飛鏢、蠟燭、鐵鎚、紙團、垃圾桶、鬼面具、豆子、福字、煞氣、五花肉、豆干、鴨蛋、供盤、金爐），由開發者使用 Google Gemini 與 Google Flow 生成，再壓縮成 WebP、去背、描輪廓（`tools/prep-art.py`）。上架 itch.io 時會勾選 AI Generated Graphics。
- **程式繪製**：紙小人的表情和變形（撕碎、揉皺、燒焦、泡爛）、玻璃罐、特效，以及每個道具的備用版本，都是 Canvas 即時畫的。每個場景也保留一套程式畫的備用版本，AI 圖沒載入時照樣能玩。

**音效**：全部用 Web Audio API 即時合成（拍打、火焰、敲釘、撕紙、水花、貓叫、呼嚕等），沒有錄音檔，也沒有人聲。

**背景音樂（AI 生成）**：〈Ascent of the Jade Throne〉（選單、結算）和〈Steps of the Jade Fox〉（遊戲中），由開發者用 Google 的 AI 音樂工具生成，可在右上角 ♫ 單獨關閉。試玩廣告另用〈Toll of the Nameless Shrine〉（恐怖開場）和〈The Bamboo Tiptoe〉，同樣是 AI 生成。上架 itch.io 時會勾選 AI Generated Sound。

## 隱私

遊戲沒有後端、不蒐集資料。輸入的名字、語言、音效設定和最佳紀錄只存在玩家自己瀏覽器的 localStorage；分享符咒圖時，圖片由玩家自己決定傳給誰。
